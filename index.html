対応範囲 / Limits

  • 1 行・2 行（(0,0,0)(1,1,1) 未満）: 規則で翻訳します。
    1 or 2 rows (below (0,0,0)(1,1,1)): translated by rules.
  • 3 行: BM4-Analysis シートにある行（(0,0,0)(1,1,1)(2,1,1)(3,1,0)(2,0,0) = ψ(I) まで）だけ対応します。 シートの順序数表記（拡張 Buchholz ψ）を C に写したもので、行列からの直接の翻訳ではありません。 「⚠ flagged」は機械検査で指摘があった行です。4 行以上は未対応です。 ψ(Ω_{Ω_2}) より上で添字に Ω_{Ω_2} 型を含む行は検査が弱く、値がずれている可能性があります。
    3 rows: only rows of the BM4-Analysis sheet up to (0,0,0)(1,1,1)(2,1,1)(3,1,0)(2,0,0) = ψ(I). The term is the sheet's ordinal label (extended Buchholz ψ) mapped to C, not a direct translation of the matrix. "⚠ flagged" marks rows where the machine checks raised something. 4 rows and more are not supported. Above ψ(Ω_{Ω_2}), rows with Ω_{Ω_2}-type subscripts are only weakly checked and their values may be shifted.
  • 2 行の規則は、原表の 2 行の全行と展開のサンプルで機械検査（標準形・順序・基本列との整合）を通っています。 証明ではありません。
    The 2-row rules pass the machine checks (standard form, order, agreement with fundamental sequences) on every 2-row row of the sheet and on sampled expansions. This is not a proof.
  • 標準形の行列を想定しています。非標準形の入力の結果は保証しません。
    Standard matrices are assumed; results for non-standard input are not guaranteed.

入力 / Input

  • 1 行に 1 行列。複数行はまとめて変換されます。/ One matrix per line; all lines are translated.
  • (),0-9 以外の文字は無視されます。/ Characters other than (),0-9 are ignored.
  • 列の高さが違うときは最大の列に合わせて 0 を詰めます: (0)(1,1) → (0,0)(1,1)。
    Shorter columns are padded with 0 to the tallest column.
  • 入力は URL の ?bms= に反映されます。/ The input is mirrored to the URL query ?bms=.

記法 / Notation

Taranovsky's C（main system, 結合系）。項は 0, Ω_n, C(a,b)。 Ω_1 = Ω。BMS は BM4。
Taranovsky's C (main system, combined). Terms: 0, Ω_n, C(a,b). Ω_1 = Ω. BMS is BM4.

1 行: C(a,b) = b + ω^a の 0 番目の系。2 行: ペア数列 → Buchholz の表記 → C。 規則の詳細と検証は リポジトリを参照。
1 row: the 0-th system with C(a,b) = b + ω^a. 2 rows: pair sequence → Buchholz's notation → C. See the repository for the rules and their verification.
